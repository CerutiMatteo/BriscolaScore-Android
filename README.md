# BriscolaScore Android

An Android scorekeeping application for **Briscola in 5**, developed using **Embarcadero Delphi**.

The application simplifies score tracking during Briscola matches, supporting up to six players when a dummy player (*morto*) is included.

## 📱 About the Project

BriscolaScore Android is a mobile application designed to help players keep track of scores during games of Briscola in 5, a traditional Italian card game.

The application provides a digital alternative to traditional pen-and-paper scorekeeping, making it easier to manage scores throughout a match.

## ✨ Features

- Score tracking for Briscola in 5
- Support for up to six players
- Management of games involving a dummy player (*morto*)
- Digital scorekeeping
- Android interface designed for mobile devices

## 🃏 What is Briscola in 5?

Briscola in 5 is a variation of the traditional Italian card game Briscola, typically played with five participants.

The game involves strategic partnerships and individual competition.

BriscolaScore Android focuses on simplifying score management during these matches.

## 🛠️ Technologies

- **Programming Language:** Object Pascal
- **Development Environment:** Embarcadero Delphi
- **Framework:** FireMonkey (FMX)
- **Platform:** Android

## 📲 Compatibility

The application was developed for Android devices.

**Tested device:**
- Xiaomi 13T Pro

Compatibility with other Android devices has not been extensively tested.

## 🚀 Getting Started

### Requirements

- Embarcadero Delphi with Android development support
- Android SDK configured in Delphi
- An Android device or compatible emulator

### Installation

1. Clone the repository:
2. Open the Delphi project file (`.dproj`) in Embarcadero Delphi.
3. Select an Android target platform.
4. Build and deploy the application.
